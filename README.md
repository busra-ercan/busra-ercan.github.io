# busra-ercan.github.io

Büşra Ercan — veri bilimi portfolyosu / data science portfolio.

Türkçe ve İngilizce, tek sayfa, bağımlılık yok. Grafiklerdeki bütün sayılar
projelerin kendi doğrulama çıktılarından alınmıştır.

| | |
| --- | --- |
| `index.html` | sayfanın tamamı, iki dil de içinde |
| `assets/css/style.css` | tasarım sistemi, açık + koyu tema |
| `assets/js/main.js` | dil ve tema geçişi, grafik ipuçları, sayı biçimi |

Yerelde çalıştırmak için:

    python3 -m http.server 8777

sonra http://localhost:8777 adresini aç.
